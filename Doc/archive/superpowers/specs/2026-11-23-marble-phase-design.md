# 弹珠阶段与轮值普攻设计

> **归档（2026-11-24）**：本文已并入[战斗规格 §12](../../../superpowers/specs/2026-07-21-combat-system-design.md)；此处仅保留历史设计稿，不再作为权威来源。

2026-11-23 · 定稿设计（原型前规格）。操作与表现参考《超级卷心菜轰击》。本文承接[单机三人队与即时出牌重构决策](2026-11-18-single-player-refactor-decisions.md)，定义用于替换原轮值普攻的弹珠阶段机制。

## 与既有系统的关系与失效标记

- **充能球（Orbs）系统**：暂时保留，与弹珠系统并存，待弹珠原型与实测完成后再评估是否移除或合流。
- **卡牌直伤口径调整**：配合本次改动，卡牌直伤通道后续统一调整为**无视防御**；弹珠阶段的轮值普攻结算**继承原普攻口径计算防御**。
- **标为失效／待重做的冲突机制**：凡与单机三人队及弹珠阶段冲突的旧机制（原自动全屏轮值普攻、固定手牌槽相关效果、旧元素连携、批量出牌前后钩子等）均标记为失效，后续在对应角色与卡牌重做时统一替换，本文不再兼容旧轮值普攻分支。

## 一轮战斗流程与阶段操作权限

1. **出牌阶段。** 战前按角色配牌，战斗中共用抽牌堆、墓地与 10 张扇形手牌上限，出牌由所属角色支付能量。卡牌可直接造成伤害、积攒增益、修改盘面/撞钉属性，或向待发队列添加弹珠。出牌期间清波沿用即时出牌规则，待当前效果结清后换波或判胜，已加入本轮待发队列的弹珠与盘面改动保留至本回合弹珠阶段。
2. **进入弹珠阶段与轮值锁定。** 玩家点击「结束出牌」且当前效果结清后进入弹珠阶段，锁定本轮轮值普攻角色：
   - **轮值公式**：按 `(TurnNumber - 1) % 队伍人数` 轮转；出牌阶段清波且保留当前回合继续作战时，`TurnNumber` 不变，轮值角色亦不变。
   - **封印与轮值**：被封印（Sealed）的角色仍正常担任本回合的轮值普攻角色（封印仅限制出牌与主动技）。
   - 三人共用同一盘面，本轮全部弹珠及场上衍生弹珠均归属轮值角色，包括队友卡牌/技能添加的弹珠。本轮 `Count` 从 0 开始累计；若待发队列与场上均无弹珠，直接跳过发射进入结算。
3. **弹珠阶段内的操作权限（含主动技与消耗品）。**
   - 玩家在弹珠阶段（瞄准、飞行与队列衔接期间，最终结算锁定前）可进行：瞄准/取消瞄准/发射、切换敌方标记、切换飞行倍速、提前结束、暂停，以及**释放主动技能与使用消耗品**。
   - **阶段条件校验**：部分技能与消耗品具有阶段或状态使用条件，不满足条件的在弹珠阶段禁止使用并拒绝请求（不消耗资源）。
   - **阶段内效果过滤**：在弹珠阶段成功释放的技能或消耗品中，**修改卡牌费用、抽牌/加手牌、补能等仅服务于出牌阶段的效果直接无效（空过）**；只有**改变战斗属性（加攻、增伤、护盾、治疗、敌方减益等）、直接伤害、加球或改盘面**等对当前及后续战斗有效的效果正常生效。
   - **实时联动**：上述操作若改变了双方属性、血量、嘲讽或导致敌人死亡/Boss 破条，须立即刷新血条扣血预览、标记合法性与提前结束资格；若导致敌方全灭，立刻中断当前飞行并按清波/判胜逻辑结算。
4. **发射、入队与多球同屏。**
   - **待发队列（Enqueue）**：遵循先入先出（FIFO）。场上无活跃球时，玩家调整角度发射并消耗队首 1 颗弹珠；取消瞄准保留待发球。通过入队加球效果新增的弹珠追加至队列尾部（界面按队列顺序展示各球属性与信息）。
   - **场上分裂／生成（SpawnActive）与多球同屏**：场上维护活跃弹珠列表 `ActiveBalls`，支持分裂或命中效果直接在场上生成新弹珠实现多球同屏。为防止无限刷球与性能失控，除在效果设计上避免自激循环外，强制设定**场上同时活跃弹珠上限暂定为 20 个**（达到上限后继续触发场上生球则抑制生成或按效果定义降级；若由某枚撞钉触发分裂，新球须在生成瞬间将该钉记入自身 `ContactedPegIds`，避免第 0 帧原地重复计分）。
   - 场上所有 `ActiveBalls` 均离盘或因困球回收后，先结清相关回收触发；若待发队列仍有球，进入下一颗的瞄准与发射。
5. **普攻结算与回合推进。** 当待发队列与 `ActiveBalls` 同时为空，或玩家满足条件后主动提前结束时，锁定最终 `Count` 并执行分配与伤害结算，取代原来的轮值普攻。完成普攻、追打及派生效果后结束玩家回合，进入敌方阶段、换波或判胜（零 `Count` 跳过伤害与命中触发）。**回合结束时的 Buff `Turns` 递减仍在弹珠结算完毕且敌方阶段之后统一执行**，确保出牌阶段与弹珠阶段内挂上的临时增益在本回合弹珠与敌方阶段完整有效。

## 盘面、物理、碰撞与合并

### 基础盘面与物理模型

- **独立逻辑坐标系与固定步长**：盘面采用与屏幕分辨率无关的独立逻辑坐标系（界面各视图仅做等比映射），**纯 C# 无头固定物理步长 60 帧/秒（`1/60s`）**推进，禁用引擎渲染帧与原生物理节点。
- **空间拓扑与重力**：采用**竖向二维重力场**。顶部与左右三面墙壁产生反弹，**底部为开放离盘出口**（球体完全越过底界即判定离盘）。
- **悬空发射口与发射规则**：发射口不置于顶壁边缘，而是**距离顶部墙壁留出明确垂直空间**（至少大于弹珠最大半径及保护距离），使球向斜上或正上方射出后能正常撞击顶壁并折返。发射速率固定，玩家只调整发射角度，**不设角度限制**。发射口与初始出射路径留保护区，禁止生成或膨胀后的撞钉覆盖发射口。
- **动能与速度钳制**：
  - 基础撞钉与墙壁碰撞存在**轻微动能损失**（基础恢复系数 `< 1.0`）；预留碰撞动量修饰接口，供后续设计中“碰撞获得额外动量/加速”效果使用。
  - 设定**最高速度阈值钳制**，防止弹珠因效果加速后单步穿越过远；同时对单个物理步内 `while (剩余时间 > 0)` 的连续碰撞迭代次数设上限（如单步最多连续反射 N 次），超出则截断该步剩余位移以防卡死。
- **固定布局与跨波继承**：首版开战放置 **4 枚固定布局的撞钉**，便于用同一发射角反复检验路线；每轮基础发放 **2 颗弹珠**。撞钉布局及标注为「本场战斗持续」的效果在整场战斗中**跨回合、跨波次继承保留**；临时效果按各自期限清理。**换波不重置盘面**；如需重置盘面，通过专属技能/效果原语（如 `ResetMarbleBoard`）接入 Boss 出场或切条技能。
- **多球碰撞约定**：`ActiveBalls` 中各弹珠之间**默认互不碰撞（相互穿透）**，仅与墙壁和撞钉碰撞。每颗球独立维护位置、速度、半径、点数、`ContactedPegIds` 与困球计时器。

### 碰撞计分与瞄准预测

- **计分公式**：每次有效撞钉接触增加 `弹珠点数 × 撞钉点数` 的整数 `Count`，按接触瞬间数值计算；墙壁反弹不计分。
- **持续贴合去重**：每颗球维护 `ContactedPegIds` 集合。当物理步内中心距 `<= r_ball + r_peg + eps` 且该钉 ID 不在集合内时，记分并加入集合；仅当后续物理步中心距严格 `> r_ball + r_peg + detachMargin` 时才移出集合，防止临界距离抖动刷分或贴钉连击。
- **同时碰撞**：同一物理步内同时接触多枚不同钉时各计一次。先结清同时发生的全部命中及计分，再统一处理膨胀、增钉与合并。弹珠与撞钉各有独立最大半径，所有成长均受上限约束。
- **瞄准预测**：读取发射前盘面快照，按真实 `1/60s` 固定步长推进，复用实弹的重力、墙壁/撞钉碰撞（撞钉取两者半径之和，撞墙计入球半径）、擦边容差、轻微动能损失与同时接触反弹规则，跳过命中效果与随机数消耗。路径长度按整条折返累计至显示上限或离盘出口截断，并在预测首次碰撞点绘制落点提示圆。飞行中触发的变径、增钉或合并会使实弹轨迹偏离预览；下一颗球待发射时按最新盘面重算预览。

### 撞钉合并

- **合并触发**：膨胀导致两枚及以上撞钉的圆盘发生重叠时合并；恰好相切时保留。
- **几何与点数规则**：
  - 合并后点数为参与合并各钉点数之和；
  - 新中心按各钉面积加权平均；
  - 新半径取 `min(撞钉最大半径, √Σr²)`；
  - 同时重叠的一组钉一次合并；若新钉继续与其他钉重叠，则**连续合并直至整个盘面几何稳定**，且新钉圆心与半径受三面墙壁裁剪以保证完全留在盘内。
- **附加效果只保留一份**：合并后新钉**最多只保留 1 份附加效果**（含其剩余次数与期限），防止多层叠加膨胀。选取优先级：优先保留**主钉**（参与合并各钉中半径最大者；平手取点数较高者；再平手取生成序号最早者）的附加效果；若主钉无效果而其他被合并钉存在效果，按相同优先级从中选取 1 份保留。
- **球位合法化与防重计**：合并本身不计命中。在全部连锁合并稳定且完成墙壁裁剪后，若场上有活跃球落入新钉内部，将该球沿最近且优先朝向非墙壁自由空间的法线移出重叠区（并做墙壁裁剪），同时将新钉加入该球的 `ContactedPegIds`，待球严格脱离后再接触才可得分。

## 主动结束与困球回收

达到下列任一条件，玩家即可点击提前结束（包括多球飞行期间）。按钮点亮后仍可继续发射或等待弹跳以积累更多 `Count`；按钮不可用时，悬停可展示未满足的条件原因：

| 条件               | 判定                                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 当前伤害已足够     | 按当前标记、嘲讽约束与伤害分配预演，全部普通敌人都会死亡，且每个 Boss 都会死亡、已受换条保护或将触发换条保护。只要仍有普通敌人能存活，就要继续检查时长条件。 |
| 本阶段达到时长门槛 | **从本阶段第一颗球实际发射后**开始累计有效游戏时间（包含后续瞄准与飞行时间，暂停时停表）。达到门槛后按钮持续可用。                                           |

- **境界一致性与飞行清场**：点击结束时，在 `1/60s` 物理步边界结清该步已发生的全部命中，再核对结束资格、回收全部活跃球、放弃剩余待发球并锁定最终 `Count`。手动结束与最后一球离盘同时发生时只结算一次。若飞行途中因撞钉附加效果或主动技/消耗品直接导致敌方全灭，则立刻中断弹珠阶段、回收场上球并按清波/判胜逻辑结算。
- **无限反弹与困球回收**：弹珠不设生命周期，允许无限反弹。每颗活跃球独立监测：连续约 **3 秒**几乎没有移动时认定为困球。判定结合固定物理步球心位移、实际行进距离与观察窗口活动范围，区分狭缝高速往返与缓慢但持续的运动。当停滞接近阈值（如连续约 1.5 秒）时界面给予微弱闪烁/进度环反馈，提示玩家即将触发回收而非卡死；恢复有效运动即重置该球计时，暂停期间停表。困球回收保留已得 `Count`，先结清该球退场触发，再处理剩余球或阶段结束。

## 轮值普攻结算与 Count 分配

### 伤害口径与旧普攻属性迁移

- **基础伤害属性**：继承原普通攻击规则。由轮值角色当前的 `PhysicalAttack` 与 `MagicAttack` 较高者（平手取物理）决定伤害类型（`Physical` / `Magical`），附带轮值角色全部 `Element` 属性标签，结算时扣减目标对应的 `PhysicalDefense` / `MagicDefense`。
- **统一缩放与管线**：
  - 对每个分到 `Count` 的目标，基础伤害为 `分配给该目标的 Count × 轮值角色对应攻击力`（合并为该目标的一次普攻受击，整轮只触发一次「完成普攻」）。
  - 倍率进入全局加算桶：`× (1 + DamageDealtScale + NormalAttackDamageDealtScale + 目标 DamageTakenScale + 目标 NormalAttackDamageTakenScale)`，不吃卡牌连携。
  - 经统一 `DamagePipeline` 处理规则减伤与护盾抵扣后写入敌人生命。
- **普攻关联属性映射**：
  - `NormalAttackCount`（+N）：当自身为本轮轮值角色时，本轮基础发射球数 `+N`。
  - `trait.follow_up`（追打 X%）：当非轮值队友持有追打时，在最终 `Count` 锁定并完成目标分配后，先结算轮值角色的基础普攻，随后对每个分到 `Count` 且**仍存活且未处于换条免疫状态**的目标，额外造成 `分配给该目标的 Count × 追打者对应攻击力 × 追打%` 的伤害（按追打者自身的物/魔判定、全部元素及目标对应防御结算，应用普攻加算倍率并走 `DamagePipeline`；多个追打取最高百分比，轮值角色自身不触发追打；已被基础普攻打死或已触发换条保护获得免疫的目标，追打跳过）。
  - `NormalAttackShieldGainScale`：按本次弹珠普攻结算造成的敌方实际生命损失转化护盾。
- **辅助转化预留**：治疗／辅助角色将 `Count` 转化为治疗或团队增益的机制列入后续重做设计，首版预留扩展接口。

### 嘲讽约束与 Count 分配算法

- **标记受嘲讽约束**：若敌方场上存在正 `Taunt`（嘲讽）单位，玩家**仅可在当前嘲讽值最高的存活可受伤敌人之间切换标记**；进入弹珠阶段时自动默认标记嘲讽值最高者（并列按敌方站位）。无嘲讽单位时可自由标记任意合法可受伤敌人。
- **分配算法**（预览与实弹共用同一套无副作用完整伤害管线）：
  1. 优先处理玩家标记且可受伤的目标。足以击杀时只分配所需的最小整数 `Count`，Boss 以当前血条为止。完全免疫或正处于换条保护的目标跳过。
  2. 其余目标中优先选择可击杀且所需 `Count` 最少者。若都无法击杀，则选择用剩余 `Count` 预计能造成最多实际扣血的目标。平手按敌方站位。分配到目标的 `Count` 从本轮余额中扣除。
  3. 敌方血条显示用**当前已得 `Count`**立即结算时的预计扣血。命中、改标记、释放技能/使用消耗品或攻防状态变化后实时刷新。最终结算复用同一分配算法，锁定各目标基础普攻结果后，再处理追打、击杀等派生效果。
- **示例**：每点 `Count` 对应 10 点物理攻击，敌人 A 有 18 血、B 有 70 血（均无防无盾）。6 `Count` 自动分配时 A 得 2 点、B 得 4 点；标记 B 时 B 得 6 点、剩 10 血。若 A 另有 5 点护盾，击杀 A 需要 3 `Count`。
- **超额与剩余记录**：结算保留**总 `Count`、已分配 `Count`、剩余 `Count` 和剩余原因**（如普通敌人全部死亡、Boss 换条保护等），供未来超杀机制使用；剩余 `Count` 留在本轮记录，不跨波继承，下轮从 0 重新累计。最后一个整数 `Count` 造成的溢出伤害单独记录（如还需 2 点伤害却打出 10 点，溢出为 8 点伤害）。

## 逻辑、表现与性能边界

| 职责       | 边界                                                                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 弹珠模拟   | 接收玩家角度、结束及允许的技能/消耗品指令，按 `1/60s` 固定物理步推进 `ActiveBalls`、撞钉、合并、`Count` 与待发队列。唯一裁定命中、反弹、困球、变径、合并、合法化推出与阶段结束，可独立无头运行。 |
| 战斗结算   | 提供轮值角色、追打队友、嘲讽约束与敌人状态，执行无副作用分配预演与最终普攻/追打提交。                                                                                                            |
| 界面与表现 | 采用实时步长累加器驱动模拟推进，每帧读取球位置并消费表现事件流；密集飘字、音效和粒子可限流或合并。支持飞行倍速切换（仅提高每渲染帧推进的物理步数，不改 `1/60s` 步长），暂停时停表。              |

### 战斗界面布局要求

- **出牌期缩略盘面与大屏预览**：战斗界面在出牌阶段提供**常驻缩略盘面**，实时显示当前撞钉布局、大小/点数、盘面附加效果及待发弹珠队列（含顺序与球属性）；并提供按钮随时切换为**大屏预览**，方便玩家在打出改盘/加球牌时检查几何变化。
- **弹珠阶段布局**：进入弹珠阶段后，底部扇形手牌收起，弹珠主盘面展开；顶部/侧方敌方单位、血条预计扣血预览、嘲讽标识、标记点击区域及可用主动技/消耗品入口保持可见与可交互。

### 性能与数据结构

- 首版采用集中存储盘面数据（4 钉基础规模下直接逐钉遍历检测）。预览随状态变化刷新，同一画面帧内仅绘制最新结果；事件缓冲与轨迹历史限制长度并复用表现对象。累计 `Count` 与伤害乘法明确数值表示范围，配合最高速度钳制与活跃球上限 20 的约束，防止长时间反弹造成内存积压或数值溢出。
- ECS 是待评估的实现选项。分别测量长时间多球高频反弹时的内存与事件积压，以及密集命中、连锁合并时的模拟、预览与渲染开销，再决定是否引入 ECS、空间分区或批量绘制。

## 首版验收与待调参数

- **四钉瞄准与重力物理**：固定角度覆盖直撞、擦边、两钉夹缝、全角度发射与悬空发射口向顶壁折返、轻微动能损失反弹及底部离盘。关闭动态效果时核对预览落点与实弹完全一致；第一次命中触发膨胀时，偏移始于该次碰撞之后。
- **多球与合并极限**：覆盖入队加球（FIFO）与场上分裂生成（含防第 0 帧原地连撞、上限 20 球截断）、球间互穿、独立困球倒计时提示与回收、三钉连锁合并、靠墙合并、合并后仅保留 1 份附加效果、发射口保护、最大半径与最高速度上限，以及球被新钉包住推出时不重复计分。
- **阶段、权限与 UI 边界**：覆盖第一颗球发射后才开始计时的时长门槛、弹珠阶段释放主动技/消耗品（有效属性变更刷新预览、改费/抽牌类效果空过、受限内容禁止使用）、飞行途中技能或效果清场中断、取消瞄准、提前结束连点、改标记使清场失效、出牌期缩略盘面与大屏切换、暂停恢复及倍速。
- **战斗结算与继承**：覆盖嘲讽约束下的标记限制、被封印角色仍正常轮值、护盾与防御扣减、免疫、平手站位、Boss 换条保护、基础普攻先决与追打跳过已死/保护目标、跨波盘面继承、Boss 技能重置盘面、清波与剩余/溢出记录；核对预览与实际扣血完全一致。
- **逻辑与表现一致性**：同一初始盘面及同一组按 `1/60s` 物理步记录的输入，在无头模式、正常画面、倍速模式和关闭特效时，应得到完全相同的命中顺序、最终 `Count`、敌方扣血与超额记录。

待原型确定的参数：重力加速度、固定发射速率、最高速度阈值、基础碰撞恢复系数、发射口悬空高度、四钉初始坐标、基础点数、两类初始/最大半径、瞄准线基础长度、提前结束时长门槛、困球位移容差与分离容差 `detachMargin`。基础 2 球、困球 3 秒（约 1.5 秒提示）、活跃球上限 20、固定步长 `1/60s` 作为首轮试验值。未来碰撞增能效果与奶妈 `Count` 转化规则，留待后续对应玩法设计。
