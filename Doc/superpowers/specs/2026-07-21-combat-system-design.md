## 1. 参与者与胜负

### 1.1 小队与敌人

- 玩家操控 **4 名角色**（槽位 0–3）；每名角色战斗内 **独立** 抽牌堆、手牌、弃牌堆。
- 敌人由战斗定义（波次 / 生成）实例化；敌方阶段按 AI / 定义行动；敌方单位使用 **独立 HP**（非共享）。

### 1.2 共享 HP（唯一玩家生命账本）

- 胜负只看 **队伍共享 HP**；**v1 无单角色倒地**。四槽在 `SharedHp > 0` 期间全程可行动、可被点名（减员压力用 **封印**，见 2.5，不用死亡态）。
- 玩家角色 **无 Health 当前值**，仅有 **MaxHealth**（贡献 `MaxSharedHp`）。凡「残血 / 生命%」类条件与效果一律读 **SharedHp / MaxSharedHp**；内容读写玩家槽位 `Health` 当前值 → 校验失败或软失败。
- `MaxSharedHp = sum(各上阵角色当前 MaxHealth)`，可在战斗中随 MaxHealth 变化 **重算**。
- **SharedHp 仅存在于本场战斗内**；Run / 非战斗层不持久化「当前共享血量」。
- 开战：在 BattleStart 被动/修饰结算之后，按当时公式得到 `MaxSharedHp`，`SharedHp = MaxSharedHp`（恒补满一次）。
- **BattleStart 通道约束**：被动自动技能与修饰技能 **禁止读写 SharedHp**（伤害、治疗、直接改血）；只允许改属性 / `MaxHealth` 等，再由补满步骤冻结账本。若将来要「带伤开战」，须另改管线，不得依赖现有顺序碰运气。
- 重算 `MaxSharedHp` 时：**不**按比例缩放 `SharedHp`；该重算路径不读改 SharedHp。若出现 `SharedHp > MaxSharedHp`，立刻 `SharedHp = min(SharedHp, MaxSharedHp)`。
- 伤害扣共享 HP；治疗加共享 HP，不超过 `MaxSharedHp`。
- `SharedHp <= 0` → 败北；敌方全灭（或战斗定义的胜利条件）→ 胜利。
- 同场 **多波**：跨波 **保留** `SharedHp` / 按规则重算的 `MaxSharedHp`，不因清波回满。

### 1.3 玩家侧点选与结算（L1 + T1 + D2 + B2）

- **点选**：卡牌/AI 仍可点 **槽位角色**（`Self` / `Ally` 等语义保留），用于点名、Buff、按槽修正。
- **分槽伤害（D2）**：对每个目标槽用该槽（及来源）ASC 分别结算；每次结果 **分别** 扣 `SharedHp`。AoE **禁止**「算一次再 ×N」。
- **内容约定**：对玩家的多目标/全体伤害，数值按 **单槽期望伤** 来写，并注明会按命中槽数多次扣 Shared。
- **Team / Shared 直伤**：与 Heal 对称；内容使用显式 **Team / Shared** 目标规格时，对账本 **只结算一次**（不走分槽点名）。禁止把「全体一次」与「分槽 AoE」混用语义。
- **内容声明方式（2026-07-28 决议）**：`ETargetScope` 新增 **`Team`** 档——`side` 继续表达敌我相对关系，`scope: Team` = 对该侧队伍账本一次结算；`scope: All` = 分槽逐次结算（D2）。玩家侧 `Heal` 必须 `scope: Team`；`Heal` + 玩家侧 `Single/All` → 内容校验失败。
- **护盾 / 格挡 / 槽位减伤**：挂在被点名的槽位上；仅当该次伤害目标含该槽时参与该次结算（B2）。Team/Shared 直伤 **不**吃分槽护盾（除非效果显式另写）。
- **治疗**：只回队伍 Shared；内容须使用显式 **Team / Shared** 目标规格。`Heal` + 点名队友（如 `Ally+Single`）→ **内容校验失败**。不存在「对某个队友回血」。

## 2. 顶层阶段机

### 2.1 节拍

1. **BattleStart**
   - 按总规格 2.2 / 4.7：**先**对每名上阵角色按槽序与潜能档尝试释放已解锁 **被动自动技能**，**再**按插入序尝试释放共享（或槽）**修饰技能**；各尝试一次（均不得读写 SharedHp，见 1.2）。
   - 然后对每名角色 **开局抽满手牌上限（5）**（见第 4、6 节）。
   - 进入首个 **玩家阶段**（走第 6 节管线；能量「当前能量」首回合不 +1；技能计数器首回合仍 +1；**首回合不再**按公式抽牌）。
2. **玩家阶段**
   - 可切换当前操控角色。
   - **出牌（标记入队）**：选手牌 → 选目标 → 标记为将执行（扣当前可用能量等，见第 3、4 节）；牌 **不离开手牌**。
   - **主动技能**：`CastActiveSkillCommand`（见第 5 节）；即时结算，不入卡牌队列；**不占**已行动。已确认角色 **仍可** 释放主动（未被封印时）；若触发回滚则按 2.3。
   - **确认 / 取消确认**：
     - **确认**：将该角色标为已行动；已确认后 **锁定** 其标记队列（不可再标记/取消标记/改目标），须先 **显式取消确认** 才能改计划。
     - **取消确认**：仅解锁编辑，**不清**已标记项。
     - **允许空确认**（零标记也可确认）。
     - 四人皆已行动（含封印视作已行动）→ **卡牌执行阶段**。
3. **卡牌执行阶段**
   - 排序：主键 = 卡牌 `priority` **降序**（**越大越先**）；同优先级按 **入队/标记序号升序**（先标记先执行）。**不用** RNG 破平局。
   - 内容约定：`priority` 为执行顺序权重；建议默认 `100`，先制 `200+`，延后 `50` 以下。
   - 结算后：该牌进入持有者 **弃牌堆**（含空放），手牌槽空出。
   - 队列清空后检查胜负；未结束则进入 **敌方阶段**。
4. **敌方阶段**
   - 执行敌人行动；回合结束钩子；四人 `HasActed = false`。
   - 检查胜负；未结束则 **回合数 +1**，再进入玩家阶段（完整回合开始管线）。

### 2.2 队列项（手牌标记）

最少字段：持有者槽位索引、卡牌 id、手牌运行时实例 id、优先级、目标集合、入队/标记序号、**入队实扣可用能量 `paid`**（Energy 费用时）。

入队 = 对手牌实例打标；取消入队 = 清除标记并按 3.3 退费；牌仍在原手牌槽。

### 2.3 玩家阶段：自动取消与未确认回滚

在 **玩家/行动阶段**，下列情况对 **相关** 已标记牌执行 **取消标记**（退还 `paid`），并将对应角色置为 **未确认**（UI 提示）：

- **相关牌**定义：目标集合 **包含** 已丢失单位的已标记牌；同角色其它仍合法目标的标记保留。多选牌只要含丢失单位 → **整张**取消标记。
- 触发例：
  - 主动技（或其它即时通道）结算后，相对施放前仍存活的敌人集合出现丢失，且上述相关牌存在。
  - 费用上涨导致自动取消（见 3.3）：取消 **至少一张** 该角色已标记牌 → 该角色回退未确认。
  - 主动技弃牌弃到已标记牌（见 4.6）。

手动取消标记（在未确认或已取消确认后）同样退 `paid`；是否回退确认态：仅当角色当前为已确认且本次改动来自「须先取消确认」流程时，确认态已由显式取消确认处理。

### 2.4 执行阶段：目标失效

- **单体**：在仍合法单体池中按 `RetargetPolicy` 重选；缺省为 **Run RNG** 在按该卡目标过滤器重算的合法池中均匀选取；池空 → **空放**（进弃牌），不回滚已行动。
- **多目标**：去掉非法目标，对 **剩余合法子集** 结算；子集为空 → 空放。不回滚已行动。

### 2.5 封印（SkipAct）

减员 / 硬控用封印，不用单角色倒地。

- **效果**：清空该角色全部手牌标记并退还各 `paid`；将该角色 **视作已行动/跳过**；本阶段 **禁止** 再标记；**禁止** `CastActiveSkillCommand`（软失败）。
- **资源**：玩家阶段开始管线（能量 / `S` / 抽牌）**照常**；管线结束后若仍处于封印，再套用上款行动封锁。
- **中途挂上封印**：立刻清标记、标已行动、禁主动；**不**回滚本阶段已获得的能量 / `S` / 牌。
- 需要「不能出牌但仍可放主动」时，另做更窄 Debuff；默认封印含禁主动。

## 3. 能量

### 3.1 定义字段与运行时

| 名称 | 来源 | 含义 |
|------|------|------|
| 初始能量 `initialEnergy` | 角色定义 | 开战时 **当前能量** 的初值 |
| 最大能量 `maxEnergy` | 角色定义 | **当前能量** 可成长到的上限 |
| 当前能量 | 运行时 | 每回合开始用来灌入「当前可用能量」的额度 |
| 当前可用能量 | 运行时 | 出牌扣费池；**可以超过** `maxEnergy` |

### 3.2 规则

- 开战：`当前能量 = clamp(initialEnergy, 0, maxEnergy)`，再按第 6 节灌可用能量。
- 每个玩家阶段开始（**非首回合**）：`当前能量 = min(当前能量 + 1, maxEnergy)`。
- 然后：**当前可用能量 = 当前能量**（覆盖，不累加残留）。
- 技能 / 效果增加的是 **当前可用能量**，可超过 `maxEnergy`；默认 **不** 提高「当前能量」成长曲线（除非另有专门效果）。

### 3.3 出牌扣费与取消（v1）

- v1 实装费用类型：**Energy**、**None**。其它 `ECostType`（Health / Gold / Discard / X）可展示，战斗入队 **拒绝**（软失败）。
- **Health 费语义预定**（本轮不实装）：将来若开放，= 扣 **SharedHp**（非槽位血），并另写预扣/执行扣与取消是否退血；不与现行 Energy `paid` 模型混用未声明。
- **Energy**：标记入队时扣 `cost`（或实现后的动态费用）点 **当前可用能量**；标记项记录 `paid`。
- **None**：不扣。
- **取消标记**：返还 `paid` 到当前可用能量；牌仍留在手牌（仅去标）。
- **费用变化（已标记）**——在 **玩家阶段内立刻** 处理（不在阶段开始统一扫）：
  - 新费用 &lt; `paid`：退还差额，更新 `paid`。
  - 新费用 &gt; `paid`：若可用能量足够则补差并更新 `paid`；**不够则自动取消该标记并退还全部 `paid`**，并按 2.3 回退该角色未确认。
- 未标记手牌：费用变化只影响可否标记，不改可用能量。

## 4. 抽牌、手牌与弃牌

### 4.1 手牌与标记模型

- 手牌槽 **固定 5**。
- **入队不离手**：标记仅表示「本回合执行阶段将结算」；执行结束（含空放）后才进弃牌并空槽。
- 未标记手牌 **跨回合保留**。
- 抽牌时若无空槽：**超出部分不处理**（不抽 / 不溢出进弃牌）。

### 4.2 每回合抽牌数（公式）

- 基准 **1**。
- 增益效果只取 **最大 +N**；减益只取 **最大 −N**（不叠多段）。
- 实际抽牌：`max(0, 1 + 最大增益 − 最大减益)`。
- **开局满手** 不走本公式；**首个玩家阶段** 不再公式抽牌。自 **第二** 个玩家阶段起，每阶段开始按公式抽。

### 4.3 中途抽牌禁令（v1）

- **禁止**一切战斗中途即时抽牌效果（卡牌 / 技能 / Buff 钩子等）。
- 技能与内容只允许投放 **抽牌数量修正**（供 4.2 公式取最大 ±N），不得即时抽牌。

### 4.4 牌堆循环

- 执行完毕（含空放）→ **弃牌堆**。
- 抽牌堆为空且 **即将抽牌**：将弃牌堆洗入抽牌堆（Run RNG），再抽。
- **每个玩家阶段最多洗牌 1 次**；若已洗过仍无法抽满，停止抽牌。
- 开局抽满 5 时同样遵守空堆洗牌规则；开局过程计为该次「进入首玩家阶段前」的抽牌，洗牌次数按实现归入 BattleStart/开局抽牌上下文（不得在首玩家阶段再公式抽）。

### 4.5 开战牌库

- 由角色当前构筑生成抽牌堆并洗牌；每人独立。

### 4.6 中途弃牌（Discard）

弃牌进该角色 **弃牌堆**（与执行后进弃牌同堆）。分通道：

1. **主动技弃牌**：可按效果弃手牌（含点选，若效果允许）。若弃到 **已标记** 牌 → 取消该标记、退还 `paid`、该角色 **回退未确认**（2.3）。
2. **卡牌执行阶段弃牌**：不可让玩家选目标牌；只能从该持有者 **未标记** 手牌中 **Run RNG 均匀随机** 弃置；已标记牌受队列保护。
3. **其它通道**（敌方行动、Buff 钩子、回合结束等）：与通道 2 相同——仅随机未标记；不得弃已标记并借此回滚确认态。

**未标记池为空**：软失败（弃 0 张），不中断该效果所属动作的其余部分；不改已标记、不回滚确认。

## 5. 主动技能与蓄力链

### 5.1 内容声明

角色定义显式字段（与扁平 `skillRefs` 分离）：

```text
activeSkillChain: [
  { skillId, cooldown },  // [0] 基础主动
  { skillId, cooldown },  // [1] 蓄力Ⅰ
  ...                     // 蓄力 N
]
```

- 至少 1 项；每项 `cooldown >= 1`。
- `Cap = sum(各档 cooldown)`。
- 战斗主动按钮 **只读** `activeSkillChain`。

### 5.2 技能计数器 `S`

- 开战：`S = 0`。
- 每个玩家阶段开始（**含首回合**）：`S = min(S + 1, Cap)`；已达 `Cap` 则不再增长。
- 可放条件：`S >= C0`（基础档冷却）。

### 5.3 释放解析（自动最高档）

一次释放 **永远** 打出当前达标的 **最高档**，玩家不可故意降档。

累计阈值（解锁区间）：

- `S >= C0` 且 `S < C0+C1` → 基础（k=0）  
- `S >= C0+C1` 且 `S < C0+C1+C2` → 蓄力Ⅰ（k=1）  
- …  
- `S >= Cap` → 最高蓄力  

示例：`C0=4, C1=6, C2=6`，`Cap=16`：

| S | 放出 |
|---|------|
| 3 | 不可放 |
| 4–9 | 基础 |
| 10–15 | 蓄力Ⅰ |
| 16 | 蓄力Ⅱ |

**扣费（溢出资保留）**：放出第 **k** 档时，扣除解锁该档的累计阈值 `T_k = C0 + C1 + … + Ck`，然后：

1. `S = max(0, S − T_k)`  
2. 再执行该技能的 `actionRefs` / `effectRefs`（此处可显式 `S+N` 做成连发）

例：`S=15` 放蓄力Ⅰ → 扣 `T_1=10` → `S=5`（溢出资保留，同阶段仍可能再放基础）。  
例：`S=10` 放蓄力Ⅰ且效果含 `S+4` → 先扣 10 → `S=0` → 效果后 `S=4` → 可再放基础。

同一玩家阶段内：扣减并跑完效果后若仍达标，允许再次释放。连发应优先靠技能效果显式加 `S`，而非只扣单档 `Ci` 留下残层。

### 5.4 指令与已行动

- 指令：`CastActiveSkillCommand(characterIndex, targets)`——**不带 skillId**，由宿主按 `S` 解析。
- **目标校验（2026-07-28 决议）**：`targets` 按指令受理瞬间解析出的 **将释放档位** 的目标规格校验；链上各档 **允许** 配置不同目标规格；UI 须跟随当前 `S` 展示对应档位的选目标模式。校验失败 → 拒绝指令（可见提示），不消耗 `S`。
- 即时结算，不入卡牌队列；**不扣**卡牌可用能量；**不占**已行动。
- **已确认**角色仍可释放（未被封印）；若触发 2.3 回滚则该角色变未确认。
- **封印**中对该槽主动软失败（2.5）。
- 卡牌 / 道具触发的 `skillRefs` / `useSkillRefs` **不走**本计数器。

### 5.5 技能载荷

- 技能被调用后，其 `actionRefs`（优先）或 `effectRefs` **同步即时执行完毕**。
- 非法技能 id：无操作（软失败）。

## 6. BattleStart 与玩家阶段开始管线（权威顺序）

### 6.1 BattleStart

1. 被动自动技能（按槽序与潜能档；禁读写 SharedHp）  
2. 修饰技能（按插入序；禁读写 SharedHp）  
3. 按公式冻结/得到当时 `MaxSharedHp`，`SharedHp = MaxSharedHp`  
4. 每名角色开局抽满手牌 5（可洗牌；不走每回合公式）  

### 6.2 每个玩家阶段开始（含首个）

对 **每名** 玩家角色依次：

1. （**非首回合**）`当前能量 = min(当前能量 + 1, maxEnergy)`  
2. `当前可用能量 = 当前能量`（覆盖）  
3. `S = min(S + 1, Cap)`（**含首回合**）  
4. （**非首回合**）按 4.2 计算实际抽牌数并抽牌（含每阶段至多一次洗牌）  
5. 若该角色处于 **封印**：清空标记并退 `paid`，视作已行动，禁主动（2.5）  
6. **不做**「阶段开始统一处理已标记费用」——费用变化在玩家阶段内即时处理（3.3）

## 7. 与代码现状的差异（实现须回写）

**2026-07-28 对齐完成**（T1–T12）。权威行为以本文 §1–§6 为准；下列为**显式遗留项**（非未对齐缺口）：

- **诊断出口**：`BlockedSharedHpWriteCount` / `RejectedSlotHealCount` / `BlockedMidDrawCount` 等仅供测试；UI/日志接入时再接 `IAppLog`。
- **更窄 Debuff**：「仅禁出牌、仍可主动」是否需要独立标签——见 §9。

## 8. 测试要点

- 能量：首回合不 +1 当前能量；次回合 +1；可用可被效果抬过 max；覆盖灌入。
- 抽牌：开局满 5 且首回合不公式抽；自第二回合起最大增益/减益不叠；手牌满停止；每阶段仅一次洗牌；中途 Draw 被拒。
- 标记：入队不离手；执行后进弃牌；取消只去标退 `paid`。
- 费用：阶段内即时 `paid` 跟踪；涨费不够自动取消并回退未确认；非 Energy 入队拒绝。
- 确认：锁定 / 显式取消确认；空确认；已确认可主动（未封印）。
- 主动：档位阈值表；释放扣 `T_k`；溢出资保留；效果 `+S` 连发；达 Cap 不再涨；不占已行动。
- 队列：priority **降序** + 入队序升序；单体 RNG 改选；多目标子集结算；目标丢失取消相关标记并回退。
- 共享 HP：BattleStart 技能不碰 Shared；MaxHealth 重算与越界 clamp；跨波保留；AoE 分槽分算；Team 直伤一次；Heal 仅 Team/Shared；无槽位 Health 当前值。
- 封印：清标记退费 + 已行动 + 禁主动；资源管线仍跑。
- 弃牌：主动弃已标记回退；执行/敌方/钩子只随机未标记；池空软失败。
