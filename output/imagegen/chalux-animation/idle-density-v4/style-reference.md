# 角色像素风格候选：克鲁克斯 idle v4

状态：待用户确认，尚未作为最终定稿。仅制作 idle。

本版相较 v3 再略提高像素密度，维持阶梯轮廓与分明色块，增加脸部、毛簇、衣褶的可读细节。统一左上方光源、简洁三级明暗，不添加随机高光、噪点或阴影变化。提示词中的像素尺寸及密度增幅是视觉目标，不是实际测定的原生逻辑像素网格。

角色身体、服饰、武器及其光影复用同一张底帧；眼睛和尾尖分别装配小区域动画。尾尖仅作最多 4 像素的局部摆动，移动时沿用原始像素颜色，不重新生成明暗。脚、腿、胸、头部轮廓与剑均不移动。最后一帧复用首帧。

验证：除眼睛和尾尖区域外，所有输出帧的 RGBA 像素完全一致，包含颜色及阴影；首尾帧完全一致。检查记录见 `manifest.json`，切帧与动画装配入口见 `package_preview.py`。

参考资源：`frames/idle-01.png` 为身份与静态光影参考，`idle-sheet.png` 为最终八帧，`idle-preview.gif` 为循环预览，`generated-sheet.png` 为内置 image_gen 原始输出，`prompt.txt` 为生成提示词。

确认风格后，其他角色使用最终批准的克鲁克斯像素帧作为颗粒、轮廓、细节层级、明暗与比例参考，各自立绘作为身份、颜色、服饰和武器参考。默认向右、透明背景、五组原地动画 `enter / idle / attack / buff / defeat`，治疗共用 `buff`。先确认每个角色的 idle，再制作剩余四组。所有动作遵循一致光源；只有姿态、遮挡或显式特效产生合理的明暗变化，禁止静止部分逐帧重绘导致闪烁。

当前每帧 432×560 为预览切帧画布；最终游戏逻辑像素尺寸仍随用户最终批准的呈现确定。
