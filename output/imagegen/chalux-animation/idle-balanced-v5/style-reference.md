# 角色像素风格候选：克鲁克斯 idle v5，中间细节

状态：待用户确认；仅生成 idle，尚未定稿。

目标：介于最初像素版本 `../raw/idle.png` 与粗颗粒当前版本 `../idle-density-v4/generated-sheet.png` 之间。毛发使用较丰富的阶梯毛簇，面部与衣褶更清楚，明暗分区保持简洁，减少第一版的细碎纹理，同时比 v4 保留更多形体细节。提示词中的像素尺寸、色数和细节比例是视觉目标，实际原生逻辑网格尚未锁定。

本版输出：`idle-preview.gif` 循环预览；`idle-sheet.png` 八帧透明图集；`frames/idle-01.png` 单帧风格参考；`generated-sheet.png` 为内置 image_gen 原始输出；`prompt.txt` 为完整生成提示词；`manifest.json` 为检查记录。

静止身体、服饰、武器与阴影使用同一底帧；眼睛眨动与末端尾尖局部摆动使用独立像素区域。固定角色根位置与双脚。尾尖移动沿用原始像素颜色，不重新生成光影。所有帧在眼睛和尾尖区域之外的 RGBA 像素完全相同，末帧与首帧完全相同；GIF 使用统一调色板，避免逐帧量化引发预览色彩闪动。

最终确认后，其他角色以批准的克鲁克斯单帧作为像素颗粒、轮廓、细节层级、比例和光影参考，以各自已确认立绘作为身份、种族、配色、服饰与武器参考。默认向右、透明背景；五组动画为 `enter / idle / attack / buff / defeat`，治疗共用 `buff`，所有动作原地进行。先确认各角色 idle 再制作其他动作；一致光源下的阴影只随姿态、遮挡和明确特效合理变化，禁止静止区域随机闪动。

当前每帧 432×560 是切帧与透明边距的预览画布，不是最终游戏逻辑像素分辨率。
