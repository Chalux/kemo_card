# 克鲁克斯 idle v6：中间细节 + 轻微呼吸试验

视觉基准：用户认可 v5 的中间像素细节，本版直接复用 v5 原始像素、配色、轮廓与明暗，不重新设计角色。当前仅试验 idle 的呼吸强度，其余四组尚未开始。

表现：每轮约 2.08 秒，八帧。胸肩抬升最多 4 个输出像素，头部跟随最多 2 像素，肩部横向摆动最多 1 像素。运动在腰部逐渐归零，角色站位和脚底不移动；保留一次短暂眨眼。本次聚焦上身呼吸，不额外摆动尾尖。

阴影沿用同一份原始像素，随相关形体运动，不重新生成光源、高光、明暗或衣褶图案。预览使用统一 GIF 调色板。末帧直接复用首帧，双脚区域在所有帧中完全一致。

资源：`idle-preview.gif` 循环预览；`idle-sheet.png` 透明八帧图集；`frames/idle-01.png` 风格基准（与 v5 相同）；`generated-motion-reference.png` 为内置 image_gen 输出的动作参考；`prompt.txt` 完整提示词；`manifest.json` 验证与动作参数；`package_preview.py` 使用批准的 v5 像素装配呼吸动画。

后续角色使用 v5 的中间细节与配色层级作为画风参考，各自立绘作为身份参考。呼吸强度待用户确认后再复用。仍采用右向、透明背景、五组原地动作 `enter / idle / attack / buff / defeat`，治疗共用 `buff`；每个角色先确认 idle 再制作其余动作。允许合理的呼吸和局部摆动，禁止根位置平移和无动作依据的阴影闪动。
